# Personal Journal

A simple way to quickly capturing  things you are learning as you are learning them.  It can become a central place for capturing important information, without the need to consider how to structure that information effectively.

A regular journal becomes a tool to reinforcing things you have learned in a language that you understand them (your own).

Creating a journal within a searchable tool provides an essential reference, reducing the need to "re-learn" things already learned.

- on-boarding tools and services being learned
- new programming language or coding techniques
- new technical or business concepts
- actions to priorities


!!! INFO "Practicalli Personal Journal"
    [Practicalli Personal Journal](https://practical.li/journal){target=_blank} is the thoughts and experiences of each week, capturing important information from work, open source projects, hobbies and health.

    Writing is done in Neovim or Emacs, using the expressive Python flavored Markdown.

    [Zensical Static Site Generator](../technical-writing/static-site/zensical.md) is used to generate a website of the journal, published via a CI worflow to GitHub Pages.
